# App icon disappearance issue
_Exported on 10/4/2026 at 15:48:15 PDT from Cursor (3.23.12)_

---

**User**

When you press the "Get started" button on the "Welcome" screen, the app icon disappears for a moment before reappearing, and then the transaction begins; this needs to be fixed. @src/components/5-welcome/2-app-logo.tsx 

---

**Cursor**

The icon flash on “Get started” is likely a remount or a style reset before the transition starts. I’ll look at the logo component and how the welcome button drives that animation.

The icon is an inline SVG inside a view transition. React promotes inline hosts to `inline-block` while it captures the old screen, and that blanks an SVG for a frame before the morph starts. I’ll give the transition an HTML box so the icon stays painted through that hand-off.

The Welcome icon now stays on screen when you press **Get started**, and the morph into the header starts from that same icon.

The view transition was capturing the SVG itself. That element is `display: inline`, and while React takes the snapshot it switches inline hosts to `inline-block`. On an SVG that blanks the icon for a frame, before the animation runs. The Welcome page also covers the logo with its piece copies for that same moment.

The transition host is now an HTML box around the icon. It keeps a non-inline display, stays visible while the page underneath is hidden, and sits above those piece copies, so the snapshot is taken from an icon that is still painted.
