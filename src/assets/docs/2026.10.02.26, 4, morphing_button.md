**How it looks**
- The solid fill is gone. The button now has a light tint (`fill-primary/8`), a 1.5px outline, and primary-colored text. A fainter second outline runs slightly ahead in time, which gives it a loose, hand-drawn feel like your sketch.
- On hover, a Motion spring makes the wobble bigger and faster, and the tint and outline get a bit stronger.
- Keyboard focus thickens the outline in the ring color.
- If the user has "reduce motion" turned on, the outline is drawn once and doesn't animate.

**How it works**
- The outline is about 9 points on a rounded-rectangle base shape. Each point moves on its own slow mix of sine waves, and a smooth closed curve is drawn through them.
- The path is a Motion value bound to `motion.path`, so the animation doesn't re-render React.
- **Settings (Valtio):** `blobButtonConfig` holds the tuning values: `points`, `wobble`, `slide`, `speed`, `squareness`, the hover multipliers, and `ghostLag`. They're read every frame, so a change shows up immediately, even from devtools.
- **Hover state (Jotai):** `blobButtonActiveAtom` holds the hover state, and setting it starts the spring.

**Why the shape is shared:** the split page transition shows inert copies of the Welcome page, each containing its own button. If each copy drew its own random shape, you'd see breaks at the seams between pieces. So the random seeds are fixed, and all copies share one animation clock and hover value. That way every copy draws the identical outline.
